## Scope
The project's own code, data and documents in this repository are licensed under the Apache License 2.0 (`LICENSE`).
Third-party material keeps its own licence:

- **Facts about upstream code.** `manifests/expA/` and `reports/` record facts about 32 upstream Python projects at
  pinned commits: repository names, commits, file paths, file hashes, function identities (`relpath::qualname`), line
  numbers, call-site counts and licence metadata. This repository does not redistribute upstream source files or
  excerpts of their source text; the frozen item build with source excerpts (payloads, graph facts) and the episode
  records ship in the separate dataset package, which carries its own notices.
- As a courtesy, and because facts about the code are derived from it, each project's licence file(s) are included
  byte for byte in `licenses/<family>/` (sha256 equal to the registry values below), together with its copyright lines.
- No upstream project endorses this repository.

## Tools and model (not redistributed)
- LocAgent (https://github.com/gersteinlab/LocAgent, commit `4935b557326c154bad8e8dcf3747cc8d32d1f387`, Apache-2.0)
  built the static graph backend; `absent_edges/graphs.py` loads it at run time from a separate checkout, and no
  LocAgent code is copied here.
- jedi 0.20.1 (MIT) is the second static backend; it is installed from PyPI, not copied.
- The evaluated models, `google/gemma-4-31B-it` (revision `518276fb130dc81caf9a4f772e65e63ef2526493`) and
  `google/gemma-4-12B-it` (revision `0e2b1058541244490925fbacf8972041435691ac`), are licensed under Apache-2.0 per their
  model cards. No weights are included; the files pin them by revision and sha256 lists only.
- The serving stack (CPython, vLLM 0.25.1, PyTorch, Transformers) is not redistributed; it is pinned by lock and hash lists.
